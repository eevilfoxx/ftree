# Документация класса Config

## Обзор

Класс `Config` реализует **одиночку (Singleton)** для управления конфигурацией приложения, предоставляя глобальный доступ к настройкам. Поддерживает загрузку конфигурации из файлов и программную установку пар "ключ-значение" с типобезопасным получением.

## Основные возможности

- **Паттерн Singleton**: Гарантирует существование только одного экземпляра в приложении
- **Конфигурация из файлов**: Загрузка настроек из внешних файлов
- **Типобезопасные геттеры**: Получение значений в конкретных типах (double, int, string)
- **Хранилище в памяти**: Быстрый доступ к значениям конфигурации
- **Значения по умолчанию**: Безопасный откат для отсутствующих ключей

## Декларация класса

```cpp
class Config {
public:
    // Точка доступа к синглтону
    static Config& getInstance();
    
    // Загрузка и модификация конфигурации
    void loadFromFile(const std::string& filename);
    void set(const std::string& key, const std::string& value);
    
    // Методы получения значений
    double getDouble(const std::string& key, double defaultValue = 0.0) const;
    int getInt(const std::string& key, int defaultValue = 0) const;
    std::string getString(const std::string& key, const std::string& defaultValue = "") const;

private:
    // Приватный конструктор и операции копирования для обеспечения паттерна Singleton
    Config();
    Config(const Config&) = delete;
    Config& operator=(const Config&) = delete;
};
```

## Детали методов

#### `static Config& getInstance()`
**Возвращает**: Ссылку на экземпляр синглтона Config  
**Использование**: 
```cpp
Config& config = Config::getInstance();
```
Это единственный способ получить экземпляр Config.

#### `void loadFromFile(const std::string& filename)`
Загружает конфигурацию из файла. Ожидаемый формат - пары "ключ-значение", по одной на строку:
```
population.initial_count = 1000
simulation.speed = 1.5
person.max_age = 80
```

**Параметры**:
- `filename`: Путь к файлу конфигурации

**Может выбрасывать исключения**: Если файл не может быть открыт или распарсен

#### `void set(const std::string& key, const std::string& value)`
Программно устанавливает значение конфигурации.

**Параметры**:
- `key`: Ключ конфигурации (например, "simulation.speed")
- `value`: Строковое представление значения

#### Геттеры значений

Все методы-геттеры следуют одинаковой схеме:

- **Параметры**:
  - `key`: Ключ конфигурации для получения
  - `defaultValue`: Значение, возвращаемое если ключ не найден
- **Возвращает**: Типизированное значение конфигурации или defaultValue если ключ отсутствует

**Методы**:
- `getDouble()`: Возвращает значение double (распарсенное из строки)
- `getInt()`: Возвращает целочисленное значение (распарсенное из строки)  
- `getString()`: Возвращает строковое значение напрямую

## Примеры использования

```cpp
// Получить экземпляр конфигурации
Config& config = Config::getInstance();

// Загрузить из файла
config.loadFromFile("settings.conf");

// Получить значения со значениями по умолчанию
int populationSize = config.getInt("population.initial_count", 1000);
double simulationSpeed = config.getDouble("simulation.speed", 1.0);
std::string logLevel = config.getString("logging.level", "info");

// Программное переопределение
config.set("simulation.speed", "2.5");
```

## Пример формата файла

Создайте файл конфигурации (`settings.conf`):
```ini
# Настройки симуляции
simulation.speed = 1.5
simulation.max_duration = 3600

# Настройки популяции  
population.initial_count = 1000
population.growth_rate = 0.02

# Настройки персонажей
person.min_age = 0
person.max_age = 100
person.marriage_age = 18
```

## Соображения потокобезопасности

⚠️ **Важно**: Данная реализация **не является потокобезопасной** по умолчанию. Создание экземпляра Singleton потокобезопасно (благодаря статической локальной переменной), но конкурентные вызовы методов модификации (`loadFromFile`, `set`) и геттеров могут привести к состоянию гонки.

**Для потокобезопасного использования**:
- Загружайте конфигурацию один раз при инициализации
- Избегайте модификации конфигурации во время выполнения
- Или добавьте защиту мьютексами если модификации необходимы

## Обработка ошибок

- Отсутствующие ключи возвращают значения по умолчанию без ошибок
- Ошибки загрузки файлов должны обрабатываться вызывающей стороной
- Ошибки преобразования типов (например, парсинг "abc" как int) будут возвращать значения по умолчанию

Этот класс предоставляет чистый, централизованный способ управления конфигурацией приложения во всем вашем проекте симуляции.
